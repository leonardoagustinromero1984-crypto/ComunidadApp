# D08-02 — Guía de uso del logo LeoVer

**Versión:** 1.0 · **Fecha:** 2026-08-05 · **Estado:** APROBADO  
**Fuente:** D08-01 · Brand Board oficial

---

## 1. Área de seguridad

Dejar un margen libre mínimo de **~10–15 %** del alto del logo alrededor del imagotipo/isotipo. En launcher Android mantener **inset ~18 %** (zona segura ~66 dp centrales) según RC1.1.

---

## 2. Tamaño mínimo

| Soporte | Mínimo recomendado |
|---------|-------------------|
| Isotipo digital | 32 dp de alto útil |
| Imagotipo en UI | 72 dp de alto (wordmark legible) |
| Launcher | Lienzo 108 dp; contenido en zona segura |

---

## 3. Usos

| Uso | Regla |
|-----|-------|
| Horizontal | Imagotipo preferido en headers / login |
| Vertical | Imagotipo centrado (splash / onboarding) |
| Isotipo solo | Espacios reducidos, launcher, favicon conceptual |
| Fondo claro | Preferido (blanco / crema `#FFF6EA`) |
| Fondo oscuro | Imagotipo a color si hay contraste; o monocromo claro |
| Monocromática | Themed icons / fondos de color fuerte |

---

## 4. Prohibiciones

1. Deformar o estirar.  
2. Rotar.  
3. Cambiar colores fuera de la paleta oficial.  
4. Agregar sombras o efectos no aprobados.  
5. Separar o reordenar perro, gato y hoja.  
6. Cambiar la escritura **LeoVer**.  
7. Usar el wordmark dentro del launcher icon.  
8. Usar la lámina Brand Board como imagen de producto.  
9. Usar identidad histórica como marca vigente.
